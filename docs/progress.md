## 열린 질문 / 막힌 점

- 두 방향 매핑을 함께 갱신할 때, 그 사이에 다른 스레드가 끼어들면 어떤 불일치가 생기나? (P1-3)
- 없는 방에 `JOIN`하면 만들까, 거절할까? 이미 들어간 방에 다시 `JOIN`하면? (P1-3)
- `ConcurrentHashMap` 반복은 weakly consistent — 브로드캐스트 중 입장·퇴장한 세션이 빠지거나 포함돼도 괜찮은가? (P1-4)
- 서버 → 클라이언트 메시지 모델도 ADR-0007과 같은 방식으로 할까? (P1-4)
- 판별된 잘못된 메시지에 어떻게 대응할까(에러 응답 형식, 연결 유지 여부), 비정상 단절 감지(ping/pong 주기·타임아웃)와 테스트 방법 (P1-5, ADR-0005)
