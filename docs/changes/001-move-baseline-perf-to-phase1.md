# CHG-001. 기준 성능 측정을 P1 종료 시점으로 이동

- 날짜: 2026-10-24
- 영향 Phase: P1, P8

## 기존 계획

부하 테스트와 성능 측정은 Phase 8에서 본격적으로 수행한다.

## 변경 내용

- P1 완료 기준에 "k6로 순수 WebSocket 브로드캐스트 기준 성능 측정 및 기록"을 추가한다.
- 이후 각 Phase에서 같은 스크립트와 조건으로 회귀를 확인한다.
- P8은 처음 측정하는 단계가 아니라, 누적된 측정치를 바탕으로 병목을 분석하고 최적화하는 단계가 된다.

## 변경 이유

원 계획 6절의 "초기 기준 성능을 측정하고 이후 개선 전후를 같은 조건에서 비교한다"는 원칙과 일치시키기 위함이다.
P8에서 처음 측정하면 DB, Kafka, Redis 도입이 성능에 각각 얼마나 영향을 주었는지 분리할 수 없다.

## 영향

- P1 범위가 늘어난다 (k6 스크립트 작성, 측정 조건 문서화).
- 측정 결과는 `phases/phase-01-websocket/experiments/`에 기록한다.

## 관련 ADR

없음 (k6 도입 여부는 P1에서 ADR로 결정)
