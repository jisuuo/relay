# CHG-003. 마스터 프롬프트를 AI 구현 위임 기반 사고력 훈련으로 교체

- 날짜: 2026-10-26
- 영향 Phase: P1-6 이후 전체

## 기존 계획

`chat-server-roadmap.md`는 "문제 발견 → 재현 → 해결책 비교 → 구현 → 테스트·측정 → 문서화"를 반복하는 학습 중심 채팅 서버 구축 프롬프트였다. 과제는 ADR-0003의 5단계 체크리스트(정의 → 고민 → 설계 → 구현·검증 → 정리)로 진행했다.

## 변경 내용

- `chat-server-roadmap.md`를 "AI 구현 위임 기반 백엔드 엔지니어링 사고력 훈련" 마스터 프롬프트로 교체한다.
- 학습자는 문제 정의·설계·검증 기준·결과 해석·최종 결정을 맡고, 코드 작성은 구현 AI에 위임할 수 있다. 핵심 로직은 설명할 수 있어야 한다.
- 과제 진행 절차를 8단계(문제 정의 → 시스템 흐름 분석 → 요구사항·불변식·제약 → 실패 시나리오 → 설계·대안 비교 → AI 구현 위임 → 검증·결과 해석 → 운영 관점·회고)로 정의한다.
- 학습 모드(이해·설계·장애 분석·구현 검토), 과제별 완료 기준 질문 10개, FLOW 기록이 추가된다.
- P1-6부터 새 절차를 적용한다. P0~P1-5의 기록과 구현은 다시 만들지 않는다.
- Phase 순서와 범위(P1-6 메트릭, P1-7 성능 측정, P1-8 느린 소비자)는 바꾸지 않는다.

## 변경 이유

기능 구현보다 처음 보는 문제를 스스로 구조화하고 판단하는 능력을 기르는 데 집중하기 위해서다.

## 영향

- 미결정: 8단계를 `plan.md` 체크리스트에 어떻게 반영할지(5단계 유지 후 세부 절차로 포함 / 8단계로 교체 후 ADR-0003 대체). P1-6 시작 전에 정한다.
- `docs/roadmap.md`의 Phase 순서·범위는 변경 없음.
